ProcureAI is deployed in namespace {{ .Release.Namespace }}.

1. Create the secrets (never templated):
   kubectl create secret generic {{ .Values.existingSecret }} \
     --from-literal=SECRET_KEY="$(openssl rand -base64 48)" \
     --from-literal=ENCRYPTION_MASTER_KEY="$(openssl rand -base64 32)" \
     --from-literal=DATABASE_URL="postgresql+asyncpg://user:pass@host:5432/procureai"

2. Run migrations and bootstrap once:
   kubectl exec deploy/{{ .Release.Name }}-api -- procureai migrate
   kubectl exec deploy/{{ .Release.Name }}-api -- procureai bootstrap --demo=false

3. UI: https://{{ .Values.ingress.host }}  API docs: https://{{ .Values.ingress.host }}/api/docs
